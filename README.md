# Canaan Church App ⛪

A Python-powered church management application designed to streamline member record management and database operations for Canaan Church.

## 🚀 Features

- **Member Management:** Store and manage church member details efficiently.
- **Database Backend:** Uses SQLite (`canaan_church.db`) for lightweight, local data storage.
- **Core Operations:** Python script (`church.py`) handling database queries and logic.
